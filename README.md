# Regional-Science-Technology-Fair-2026-Champion-Maze-Solver
An autonomous maze-solving robot developed for the Regional Science Technology Fair (RSTF) 2026, where it earned the Champion award. The robot was designed to navigate a maze independently using sensors, programmed logic, and precise motor control.


## How It Works

The IR sensors continuously detect the maze walls.
The Arduino processes the sensor data.
Based on the programmed maze-solving algorithm, the robot decides whether to move forward, turn left, or turn right.
The motor driver controls the motors according to the Arduino's commands.
The robot repeats this process until it reaches the finish line.

## Hardware

This project uses the AD176 Maze Solver Robot Kit, which includes:

- Arduino Uno and Motor shield
- L298N Motor Driver
- 4 TT Gear Motors
- 3 Infrared line Sensors
- Ultrasonic Sensor
- Robot Chassis
- 4 Omnidirectional Wheels
- Battery Holder
